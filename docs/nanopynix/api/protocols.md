# Protocols

Transport-neutral `typing.Protocol` definitions shared by the RPC-based
`nanopynix.Store`/`nanopynix.EvalSession` and the direct-pointer
`nanopynix.inproc.Store`/`nanopynix.inproc.EvalSession`. Depend on these when
writing code that should work with either transport.
